# The Fractured Archives

A RuneLite plugin that will include many features for activities throughout **The Fractured Archives**.

> **Work in progress:** The plugin will have many features, but currently only the starting-area mining activity is included.

## Current Features

- Highlights clickable Ascension rocks in the starting area.
- Ignores decorative and unmineable rocks.
- Detects the bonus Sprite when it appears.
- Sends an optional notification when a Sprite spawns.
- Highlights the Sprite and its nearby Ascension rock with a separate color.
- Supports configurable rock and Sprite highlight colors.

## Supported Area

The current release supports the mining activity in region `16470`.

## Configuration

- **Rock color:** Changes the highlight used for normal mineable Ascension rocks.
- **Sprite rock color:** Changes the highlight used for the Sprite and its nearby bonus rock.
- **Sprite notifications:** Enables or disables the notification shown when a Sprite appears.

## Planned Work

Support for more activities and areas within The Fractured Archives will be added as their mechanics are documented.

## Installation

The plugin is being prepared for submission to the RuneLite Plugin Hub. After acceptance, search for **The Fractured Archives** in the Plugin Hub.
